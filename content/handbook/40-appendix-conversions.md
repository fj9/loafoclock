The handbook uses metric measures throughout. These tables help if you use cups or Fahrenheit. Weigh flour rather than measuring it in cups, because a cup of flour can vary a lot depending on how it is scooped.

## Temperatures

| Celsius | Fahrenheit | Where it appears |
|---|---|---|
| 3°C | 37°F | fridge, low |
| 5°C | 41°F | fridge, high |
| 18°C | 64°F | cool kitchen |
| 20°C | 68°F |  |
| 22°C | 72°F |  |
| 24°C | 75°F | usual dough temperature |
| 26°C | 79°F |  |
| 27°C | 81°F | warm dough |
| 30°C | 86°F | warm water |
| 96°C | 205°F | loaf done, low |
| 99°C | 210°F | loaf done, high |
| 180°C | 355°F | reviving stale bread |
| 230°C | 445°F | lid-off bake |
| 240°C | 465°F | lid-on bake |
| 250°C | 480°F | open bake |

Fahrenheit figures are rounded. Oven temperatures are rounded to the nearest 5°F.

Oven temperatures in this handbook are for fan ovens. For a conventional (non-fan) oven, set it about 20°C (35°F) higher, if your pot allows, and go by the colour of the loaf.

Gas mark 9 is 240°C in a conventional oven, which is about 220°C in a fan oven.
